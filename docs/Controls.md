Модуль Player Queue — Руководство пользователя
Модуль содержит два независимых инструмента: Очередь игроков и Диалоговая сцена. Они интегрированы между собой, но можно использовать каждый отдельно.


Система 1 — Очередь игроков
Зачем это нужно
Очередь позволяет игрокам «поднять руку» и обозначить, что они хотят высказаться или совершить действие. ГМ видит всех желающих с их приоритетом и может вызывать их по порядку.


Для игроков
Как попасть в очередь:
Нажмите кнопку со значком группы людей на панели управления сценой (левая панель инструментов Foundry) — откроется окно очереди. Выберите приоритет:


Кнопка	Приоритет	Когда использовать
!	Низкий	Хочу что-то добавить, не срочно
!!	Средний	Хочу высказаться в ближайшее время
!!!	Высокий	Срочно, это важно прямо сейчас

После входа в очередь можно изменить приоритет кнопками в том же окне или выйти кнопкой «Покинуть очередь».


Floating-виджет (плавающая иконка с портретами) появляется на экране автоматически, когда кто-то встаёт в очередь. Он перетаскивается в любое место экрана — позиция сохранится.


Для ГМ
Управление очередью:


В окне очереди и в floating-виджете каждый игрок отображается с цветной рамкой по его приоритету:


🟢 Зелёная — низкий

🟡 Жёлтая — средний

🔴 Красная — высокий

Очередь сортируется автоматически: сначала высокий приоритет, внутри одного приоритета — по времени входа (кто раньше встал — того и тапки).


Действия с игроком:


ЛКМ на портрет — объявляет игрока в чат («🎭 Имя сейчас выступает!») и убирает из очереди

ПКМ на портрет — молча убирает из очереди без объявления

«Очистить очередь» — кнопка в окне, убирает всех разом.


Настройки очереди
Открываются через Foundry → Настройки модулей → Player Queue.


Настройка	Описание
Позиция очереди по умолчанию	Угол экрана, где появляется виджет при первом запуске
Ориентация очереди	Портреты в ряд горизонтально или вертикально
Размер портретов	30–100 пикселей
Максимум видимых игроков	После этого числа виджет становится прокручиваемым
Включить звуки	Звуковые уведомления при смене приоритета
Громкость звуков	0–100%
Звуки только для себя	Слышать только свои уведомления, не чужие
Тёмная тема	Тёмное оформление виджета очереди
Плашка имени персонажа	Стиль рамки под именем в диалоговой сцене (см. ниже)

Кнопка «Открыть тест звуков» позволяет прослушать все три звука с текущими настройками громкости.


Система 2 — Диалоговая сцена
Зачем это нужно
Диалоговая сцена — это полноэкранный кинематографичный оверлей: портреты персонажей на фоне с атмосферными эффектами. Используется для ключевых встреч, диалогов, кат-сцен. ГМ управляет сценой, игроки видят её синхронно.


Создание сцены (только ГМ)
Введите в консоли браузера openVisualNovelScene() или используйте кнопку в панели инструментов (если настроена). Откроется диалог с четырьмя вкладками.

Размер диалога запоминается: если растянуть окно, при следующем открытии оно появится в том же размере.


Вкладка «Персонажи»
Здесь вы расставляете персонажей по позициям на сцене.


Доступные токены — список всех токенов текущей карты Foundry, у которых есть привязанный актёр. Перетащите нужного персонажа в одну из трёх зон:


← Лево — левая сторона экрана

Центр — по центру

Право → — правая сторона

Порядок карточек внутри зоны определяет глубину: первый = ближний план, последний = дальний план (уменьшается). В каждой зоне помещается до 9 персонажей (3 ряда по 3).


Избранное — боковая панель для актёров, которых часто добавляете. Перетащите актёра прямо из журнала Foundry Actors сюда. ПКМ по записи — удалить из избранного. Из избранного тоже можно перетаскивать в позиционные зоны.


Скрытый персонаж — на каждой карточке в позиционной зоне есть кнопка-глаз (👁). Нажмите, чтобы персонаж отображался как чёрный силуэт с именем «???» — игроки не увидят кто это. Нажмите снова — персонаж возвращается к нормальному виду. То же самое можно сделать на живой сцене: ПКМ по портрету (только ГМ).


Кнопки внизу диалога:


«Создать» / «Обновить» — запускает сцену

«Только фон» / «Убрать персонажей» — запускает без персонажей (только фон и атмосфера)

Вкладка «Фон»
Галерея фоновых изображений и видео из папки модуля. Поддерживаются jpg, png, webp, gif, mp4, webm.


Кликните на фон — он выбирается

Наведите — предварительный просмотр на сцене

Папки открываются кликом, навигация по вложенным каталогам

«Использовать фон текущей сцены» — взять фон карты Foundry

Поле ввода пути — указать изображение вручную

«Затемнение фона» — добавляет тёмный полупрозрачный слой поверх фона (рекомендуется для читаемости портретов)

«Атмосфера» — выпадающий список из 28 эффектов (частицы, погода, магия и т.д.)

Музыка сцены — перетащите любой трек из панели Плейлисты Foundry в зону «Перетащите трек сюда». Отображается как «Плейлист — Трек». Кнопка × очищает выбор. При запуске сцены все активные треки Foundry ставятся на паузу (позиция сохраняется), трек сцены запускается по кругу. При закрытии сцены трек останавливается и паузированные треки возобновляются.


Вкладка «Пресеты»
Сохраняйте расстановку персонажей, фон, атмосферный эффект, музыку, размеры портретов и прочие настройки как именованный пресет.


Строка сохранения
Введите название → нажмите «Сохранить». Одинаковое название не перезаписывает старый пресет — создаётся новый.

Кнопка 📌 (булавка) рядом с полем названия — по умолчанию активна, если открыта карта Foundry. Когда активна, пресет привязывается к текущей сцене и появляется в её группе. Нажмите, чтобы сохранить пресет без привязки к сцене.


Панель инструментов списка
Поиск — фильтр по названию в реальном времени.

«Эта сцена» — показывает только пресеты, привязанные к текущей карте Foundry.

Переключатель вида — список (строки) или карточки (сетка с превью фона и аватарами персонажей).

«Удалить все» (красная кнопка) — удаляет все пресеты с подтверждением.

«Перегенерировать все» — перезапускает генерацию превью и данных портретов для всех пресетов сразу (полезно после обновления модуля).


Группировка по сценам
Если у пресетов есть привязка к сценам, список автоматически разбивается на группы по имени сцены. Для каждой группы доступны кнопки (появляются при наведении на заголовок группы):

Перегенерировать группу — регенерация всех пресетов в группе.

Удалить группу — удаление всех пресетов группы с подтверждением.


Действия с пресетом
Действие	Описание
▶ Запустить	Сразу создаёт сцену из пресета и закрывает диалог
↑ Загрузить в диалог	Заполняет диалог данными пресета, не запуская сцену
🔄 Обновить из диалога	Перезаписывает пресет текущими настройками диалога (с подтверждением)
↺ Перегенерировать	Обновляет превью и данные портретов для этого пресета
📌 Изменить сцену	Привязать к текущей сцене, переназначить или отвязать
✏️ Переименовать	Редактирование названия на месте
🗑 Удалить	Удаление с подтверждением

Пресеты хранятся на уровне мира Foundry — в другом мире они не появятся.


Вкладка «Приключения»
Экспорт и импорт пресетов для обмена с другими мастерами или сохранения резервных копий.


Экспорт
Отметьте нужные пресеты галочками (есть кнопки «Выбрать все» / «Снять все»).

«Скачать JSON» — скачивает отмеченные пресеты (или все, если ничего не отмечено) как файл на компьютер.

«Экспортировать в модуль» — записывает пресеты в файл на сервере Foundry внутри выбранного модуля приключений. После экспорта появляется диалог с готовым фрагментом module.json и кнопкой «Скопировать» — вставьте его в module.json своего приключения, чтобы модуль мог находить эти пресеты при импорте.


Импорт из модуля приключений
«Найти модули приключений» — сканирует все установленные модули Foundry на наличие пресетов Player Queue.

Нажмите «Загрузить» рядом с нужным модулем — появится список его пресетов с галочками.

«Импортировать выбранные» — добавляет отмеченные пресеты. Если есть дубликаты, предлагает выбор: только новые или перезаписать дубли.


Импорт из файла JSON
«Выбрать файл .json» — открывает выбор файла. После выбора показывает диалог с тремя вариантами:

Только новые — добавить пресеты, которых ещё нет.

Перезаписать дубли — добавить новые и заменить совпадающие (появляется только если есть дубликаты).

Заменить всё — удалить все текущие пресеты и загрузить из файла.

Панель ГМ (нижняя полоска)
Кнопка	Действие
⚙️ Настройки	Открыть диалог редактирования
[иконка эффекта] Атмосфера	Открыть сетку всех эффектов; кликните на нужный — применится сразу для всех

Когда сцена свёрнута, появляется полоска с кнопками «Развернуть для всех» и «Развернуть для себя».

Игроки видят только кнопку «Закрыть» — которая закрывает сцену только у них.


Управление размером портретов (верхний левый угол, только ГМ)
Глобальный масштаб (влияет на всех персонажей):

Кнопки − и + — уменьшить/увеличить на 10% для всех игроков

Цифра в центре (например «80%») — нажмите для сброса на 100%

Кнопка слайдеров — открывает детальный диалог с ползунком (50–200%), быстрыми пресетами и кнопкой «Для всех»

Индивидуальный масштаб (только для одного персонажа):

Alt + прокрутка колеса по портрету — увеличить или уменьшить размер конкретного персонажа на 5% за шаг, не трогая остальных. Запоминается в пресете.


Взаимодействие с персонажами
Действие	Кто	Результат
ЛКМ по портрету	Все	Переключить персонажа как активного говорящего (свечение + анимация). Повторный клик — снять.
Ctrl + ЛКМ по портрету	Все	Сделать этого персонажа единственным говорящим: сбрасывает всех активных говорящих во всех зонах, затем активирует только выбранного.
СКМ (колесо) по портрету	ГМ	Отзеркалить портрет горизонтально
ПКМ по портрету	ГМ	Скрыть/показать персонажа (силуэт + «???»)
Alt + Прокрутка колеса	ГМ	Изменить индивидуальный размер этого персонажа (±5% за шаг)

Обычный ЛКМ: в каждой из трёх зон (лево/центр/право) одновременно может быть один активный говорящий.
Ctrl+ЛКМ: сбрасывает всех говорящих во всех зонах и активирует только выбранного.


Очередь на сцене
Если в очереди есть игроки, на сцене появляется панель с их портретами. ГМ может управлять очередью прямо оттуда: ЛКМ — объявить и убрать, ПКМ — тихо убрать. Персонажи, чьи игроки стоят в очереди, светятся соответствующим цветом приоритета.


Клавиатура
Escape — закрыть сцену (для каждого пользователя своё нажатие); если открыт выбор атмосферы — закрывает его

Сохранение состояния
Активная сцена автоматически сохраняется: если ГМ перезагрузит страницу, сцена восстановится в том же виде, включая расстановку персонажей, фон, атмосферу, скрытых персонажей, перевёрнутые портреты, индивидуальные размеры и активных говорящих.
