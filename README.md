# player-queue
# Модуль Player Queue — Руководство пользователя

Модуль содержит два независимых инструмента: **Очередь игроков** и **Диалоговая сцена**. Они интегрированы между собой, но можно использовать каждый отдельно.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

# Система 1 — Очередь игроков

## Зачем это нужно
Очередь позволяет игрокам «поднять руку» и обозначить, что они хотят высказаться или совершить действие. ГМ видит всех желающих с их приоритетом и может вызывать их по порядку.

## Для игроков
### Как попасть в очередь:

Специальные макросы позволяют сразу встать в очередь или открыть окно очереди
Выберите приоритет:

**`!` — Низкий**  
Хочу что-то добавить, не срочно

**`!!` — Средний**  
Хочу высказаться в ближайшее время

**`!!!` — Высокий**  
Срочно, это важно прямо сейчас

**Floating-виджет** (плавающая иконка с портретами) появляется на экране автоматически, когда кто-то встаёт в очередь. Он перетаскивается в любое место экрана — позиция сохранится.

## Для ГМ
### Управление очередью:

В окне очереди и в floating-виджете каждый игрок отображается с цветной рамкой по его приоритету:

:green_circle: **Зелёная** — низкий

:yellow_circle: **Жёлтая** — средний

:red_circle: **Красная** — высокий

Очередь сортируется автоматически: сначала высокий приоритет, внутри одного приоритета — по времени входа (кто раньше встал — того и тапки).

### Действия с игроком:

**ЛКМ на портрет** — объявляет игрока в чат («:performing_arts: Имя сейчас выступает!») и убирает из очереди.

**ПКМ на портрет** — молча убирает из очереди без объявления.

**«Очистить очередь»** — кнопка в окне, убирает всех разом.

## Настройки очереди

**Foundry → Настройки модулей → Player Queue**

# Вкладка «Фон»

Галерея фоновых изображений и видео из папки модуля(там пусто, но вы можете закинуть свое дерево папок с картинками в assets/scenes в модуль). Поддерживаются:

`jpg, png, webp, gif, mp4, webm`

**«Использовать фон текущей сцены»** — взять фон карты Foundry. (плохо работает с нативными уровнями, но они и не нужны для диалогов)

**Поле ввода пути** — указать изображение вручную.

**«Затемнение фона»** — добавляет тёмный полупрозрачный слой поверх фона (рекомендуется для читаемости портретов).

**«Атмосфера»** — выпадающий список из 28 эффектов (частицы, погода, магия и т.д.).

## Музыка сцены

Перетащите любой трек из панели **Плейлисты Foundry** в зону **«Перетащите трек сюда»**.

При запуске сцены все активные треки Foundry ставятся на паузу (позиция сохраняется), трек сцены запускается по кругу.

При закрытии сцены трек останавливается и остановленные треки возобновляются.

# Вкладка «Пресеты»
Сохраняйте расстановку персонажей, фон, атмосферный эффект, музыку, размеры портретов и прочие настройки как именованный пресет.

## Строка сохранения
Введите название → нажмите **«Сохранить»**.

Кнопка :pushpin: (булавка) рядом с полем названия — по умолчанию активна, если открыта карта Foundry. Когда активна, пресет привязывается к текущей сцене и появляется в её группе. Можно выключить и тогда никакой привязки к сцене не будет. Привязка нужна только для фильтрации, никаких ограничений она не накладывает.

## Панель инструментов списка

**Поиск** — фильтр по названию в реальном времени.
**«Эта сцена»** — показывает только пресеты, привязанные к текущей карте Foundry.
**Переключатель вида** — список (строки) или карточки (сетка с превью фона и аватарами персонажей).
**«Удалить все»** (красная кнопка) — удаляет все пресеты с подтверждением.
**«Перегенерировать все»** — перезапускает генерацию превью и данных портретов для всех пресетов сразу (полезно после обновления модуля).

## Группировка по сценам

Если у пресетов есть привязка к сценам, список автоматически разбивается на группы по имени сцены.
Для каждой группы доступны кнопки (появляются при наведении на заголовок группы):

**Перегенерировать группу** — регенерация всех пресетов в группе.
**Удалить группу** — удаление всех пресетов группы с подтверждением.

## Действия с пресетом

**▶ Запустить**  
Сразу создаёт сцену из пресета и закрывает диалог.

**↑ Загрузить в диалог**  
Заполняет диалог данными пресета, не запуская сцену.

**:arrows_counterclockwise: Обновить из диалога**  
Перезаписывает пресет текущими настройками диалога (с подтверждением).

**↺ Перегенерировать**  
Обновляет превью и данные портретов для этого пресета.

**:pushpin: Изменить сцену**  
Привязать к текущей сцене, переназначить или отвязать.

**:pencil2: Переименовать**  
Редактирование названия на месте.

**:wastebasket: Удалить**  
Удаление с подтверждением.

Пресеты хранятся на уровне мира Foundry — в другом мире они не появятся.

# Вкладка «Приключения»
Экспорт и импорт пресетов для обмена с другими мастерами или сохранения резервных копий.

## Экспорт
Отметьте нужные пресеты галочками (есть кнопки **«Выбрать все» / «Снять все»**).

### «Скачать JSON»
Скачивает отмеченные пресеты (или все, если ничего не отмечено) как файл на компьютер.

### «Экспортировать в модуль»
Записывает пресеты в файл на сервере Foundry внутри выбранного модуля приключений.

После экспорта появляется диалог с готовым фрагментом `module.json` и кнопкой **«Скопировать»** — вставьте его в `module.json` своего приключения, чтобы модуль мог находить эти пресеты при импорте.

## Импорт из модуля приключений
**«Найти модули приключений»** — сканирует все установленные модули Foundry на наличие пресетов Player Queue.

Нажмите **«Загрузить»** рядом с нужным модулем — появится список его пресетов с галочками.

**«Импортировать выбранные»** — добавляет отмеченные пресеты. Если есть дубликаты, предлагает выбор:
• Только новые.
• Перезаписать дубли.

## Импорт из файла JSON
**«Выбрать файл .json»** — открывает выбор файла.

После выбора показывает диалог с тремя вариантами:

**Только новые** — добавить пресеты, которых ещё нет.
**Перезаписать дубли** — добавить новые и заменить совпадающие (появляется только если есть дубликаты).
**Заменить всё** — удалить все текущие пресеты и загрузить из файла.

# Управление размером портретов

## Верхний левый угол, только ГМ

### Глобальный масштаб (влияет на всех персонажей):
Кнопки **−** и **+** — уменьшить/увеличить на 10% для всех игроков.
Цифра в центре (например **«80%»**) — нажмите для сброса на 100%.
Кнопка слайдеров — открывает детальный диалог с ползунком (50–200%), быстрыми пресетами и кнопкой **«Для всех»**.

### Индивидуальный масштаб (только для одного персонажа):
**Alt + прокрутка колеса по портрету** — увеличить или уменьшить размер конкретного персонажа на 5% за шаг, не трогая остальных.

Запоминается в пресете.

# Взаимодействие с персонажами

## ЛКМ по портрету
**Результат:** Переключить персонажа как активного говорящего (свечение + анимация). Повторный клик — снять.

## Ctrl + ЛКМ по портрету
**Результат:** Сделать этого персонажа единственным говорящим: сбрасывает всех активных говорящих во всех зонах, затем активирует только выбранного.

## СКМ (колесо) по портрету
**Результат:** Отзеркалить портрет горизонтально.

## ПКМ по портрету
**Результат:** Скрыть/показать персонажа (силуэт + «???»).

## Ctrl + Прокрутка колеса
**Результат:** Изменить индивидуальный размер этого персонажа (±5% за шаг).

# Очередь на сцене(на деле штука с багами, как нибудь посмотрю, а может выпилю от сюда, ни разу за все это время не пригодилась)

Если в очереди есть игроки, на сцене появляется панель с их портретами.

ГМ может управлять очередью прямо оттуда:

**ЛКМ** — объявить и убрать.

**ПКМ** — тихо убрать.

Персонажи, чьи игроки стоят в очереди, светятся соответствующим цветом приоритета.
